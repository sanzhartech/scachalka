# Scachalka

**Скачивай легко** — быстрый, нативный графический интерфейс для Windows, раскрывающий всю мощь **yt-dlp** и **FFmpeg** в современном и удобном оформлении. Вставляйте ссылки, загружайте целую медиатеку Apple Music или CSV-файл на 10 000 строк — Scachalka сделает всё остальное.

Scachalka не переписывает логику скачивания заново — она эффективно управляет локально установленными утилитами **yt-dlp** и **FFmpeg** через запуск процессов, предоставляя надёжный, отзывчивый и защищённый от сбоев интерфейс.

## Возможности

### Загрузка
- Вставка одной или нескольких ссылок (через пробел или с новой строки), поддержка Drag & Drop, сочетание клавиш `Ctrl+Shift+V` (вставить из буфера и сразу добавить в очередь).
- Предварительная валидация URL: некорректные ссылки отсекаются мгновенно и не доходят до уровня выполнения процессов.
- **Плейлисты**: один переключатель позволяет скачивать весь плейлист целиком в отдельную подпапку вида `<плейлист>/NN - название`.
- Очередь загрузок с контролируемым параллелизмом (по умолчанию 2 одновременных потока).
- Детальный прогресс-бар, скорость, оставшееся время (ETA), размер и текущая стадия для каждого элемента (получение метаданных → скачивание → сведение потоков → конвертация).
- Отмена (с корректным завершением всего дерева процессов yt-dlp/ffmpeg и удалением временных файлов `*.part`) и возможность повтора загрузки.

### 🎵 Импорт библиотеки Apple Music

Экспортируйте медиатеку из приложения Apple Music в текстовый файл (`songs.txt`), нажмите **«Импорт библиотеки Apple Music»** — и каждый трек будет автоматически найден и скачан. Никакого ручного поиска и копирования ссылок.

- Поддержка текстового экспорта Apple Music / iTunes (с разделителями табуляции, кодировками UTF-16/UTF-8, русскими и английскими заголовками), а также простых списков формата `Исполнитель - Трек`.
- Поиск одновременно в **YouTube и YouTube Music** (`ytsearch10:` + music.youtube.com) через yt-dlp: скачиваются только метаданные, без лишнего интернет-трафика.
- **Интеллектуальный алгоритм сопоставления** с оценкой уверенности 0–100%: анализ схожести названий, проверка исполнителя (официальный канал, авто-каналы `- Topic`), сравнение длительности трека и учёт маркеров подлинности (Official Audio / Official Music Video / VEVO / верифицированный канал).
- **Защита от изменённых версий**: nightcore, slowed + reverb, sped up, bass boosted, ремиксы, мэшапы, каверы, караоке, инструменталы, концертные записи (live), AI-версии и lyric-видео получают существенные штрафные баллы — точность важнее скорости.
- Пропущенные треки сохраняются в файл `failed_songs.txt` с точной причиной (`No match found` / `Confidence too low`); процесс никогда не прерывается из-за единичной ошибки.
- Отображение прогресса в реальном времени (`Поиск 12 / 508`, `Найдено: Official Audio · Уверенность: 98%`) и итоговая сводка с общим количеством треков и затраченным временем.
- Масштабируемость на медиатеки из тысяч композиций — поиск и скачивание выполняются параллельно.

### 📄 Массовый импорт ссылок

Импортируйте сотни и тысячи ссылок на YouTube и YouTube Music из файла — каждая валидная ссылка сразу поступает в общую очередь загрузки.

- **CSV** — колонка с URL определяется автоматически по заголовку (`youtube_music_url` / `youtube_url` / `url` / `link`), остальные столбцы игнорируются; корректно поддерживаются экранированные поля и разделители `,`, `;`, табуляция.
- **JSON** — массивы строк с URL, массивы объектов (с соответствующими ключами без учёта регистра) или корневой объект со списками.
- **TXT** — по одной ссылке на каждую строку.
- Автоматическое определение формата файла; модульная архитектура импортера позволяет быстро подключать новые форматы (M3U, выгрузки из Spotify и др.).
- Проверка ссылок на принадлежность к поддерживаемым доменам (`youtube.com`, `music.youtube.com`, `youtu.be`, `m.youtube.com`) с фиксацией статуса по каждому элементу.
- **Умное распознавание дубликатов** — одно и то же видео в форматах `youtu.be/…`, `watch?v=…` и в YouTube Music считается одной ссылкой; исходный порядок импорта сохраняется.
- Отклонённые ссылки записываются в `failed_links.txt` (`Invalid URL` / `Unsupported domain` / `Missing URL` / `Duplicate`); итоговое окно показывает число импортированных, добавленных в очередь, дубликатов и некорректных записей.
- Оптимизировано для 10 000+ ссылок: чтение файла, парсинг и валидация выполняются в фоновом потоке без зависания интерфейса.

### Форматы
- Видео: **MP4**, **MKV** с ограничением максимального качества: Best / 4K / 1440p / 1080p / 720p / 480p / 360p.
- Аудио: **MP3, M4A, OPUS, FLAC, WAV** — исходный аудиопоток наилучшего качества, конвертируемый через FFmpeg.

### Вся мощь yt-dlp (Расширенные настройки)
- Встраивание метаданных, глав (chapters), обложек (thumbnail) и субтитров с выбором языков.
- **Импорт Cookies из браузера** (Chrome, Edge, Firefox, Brave, Opera, Vivaldi) для загрузки приватных видео, контента с возрастными ограничениями или роликов для спонсоров. Если браузер запущен и блокирует свою базу cookies, Scachalka автоматически повторяет попытку загрузки без cookies вместо выдачи ошибки.
- **Поле произвольных аргументов yt-dlp** — любые флаги и параметры yt-dlp (`--limit-rate`, `--proxy`, `--live-from-start`, SponsorBlock и др.); передаются в конце строки вызова и могут переопределять любые стандартные параметры.

### Комфорт и удобство
- **Двуязычный интерфейс (Русский / Английский)** с мгновенным переключением на лету и автоопределением языка операционной системы.
- Тёмная и светлая темы оформления (тёмная по умолчанию, переключение без перезапуска, поддержка тёмного заголовка окна в Windows 11).
- Окно логов + сохранение журналов сессий в папку `%APPDATA%\Scachalka\logs`.
- Быстрое открытие папки сохранения и показ скачанного файла в Проводнике Windows.
- Корректная обработка Unicode-символов в именах файлов, понятные локализованные сообщения об ошибках.
- Сохранение настроек в формате JSON (папка сохранения, формат, качество, тема, язык, расширенные параметры).

## Системные требования

| Требование | Примечание |
|---|---|
| Windows 10/11 x64 | Поддерживаются 64-битные версии Windows |
| [yt-dlp](https://github.com/yt-dlp/yt-dlp) | Установка через терминал: `winget install yt-dlp.yt-dlp` |
| [FFmpeg](https://ffmpeg.org) | Установка через терминал: `winget install Gyan.FFmpeg` (или в комплекте с пакетом yt-dlp) |
| .NET 8 SDK | **Только для сборки из исходников** — готовый exe-файл полностью автономен |

Scachalka находит утилиты автоматически: рядом с `Scachalka.exe` → подпапка `tools\` → системная переменная `PATH` → ссылки WinGet. Если утилиты не обнаружены, баннер в приложении подскажет, как их установить; после этого достаточно нажать **«Проверить утилиты заново»**.

## Загрузка и запуск (для пользователей)

1. Скачайте `Scachalka.exe` из [раздела последних релизов](../../releases/latest).
2. Установите yt-dlp и FFmpeg (см. раздел «Системные требования»).
3. Запустите `Scachalka.exe` — установка и права администратора не требуются. Файлы конфигурации хранятся в `%APPDATA%\Scachalka\`.

### Импорт медиатеки Apple Music

1. В приложении Apple Music (или iTunes): выберите треки или плейлист → **Файл → Медиатека → Экспортировать плейлист…** → сохраните как текстовый файл (`songs.txt`).
2. В Scachalka: выберите желаемый аудиоформат (по умолчанию MP3), нажмите кнопку **«Импорт библиотеки Apple Music»** и укажите сохранённый файл.
3. Следите за ходом выполнения. Песни, для которых не удалось с высокой степенью уверенности найти соответствие, будут записаны в файл `failed_songs.txt` рядом с вашими загрузками.

### Массовый импорт ссылок

Подготовьте файл CSV, TXT или JSON со ссылками (см. поддерживаемые форматы выше), нажмите **«Массовый импорт ссылок»**, выберите файл — все корректные и уникальные ссылки будут добавлены в очередь и загружены автоматически. Отклонённые ссылки попадут в `failed_links.txt` с подробным описанием причин.

## Сборка из исходников (для разработчиков)

```powershell
git clone https://github.com/sanzhartech/scachalka.git
cd scachalka
dotnet publish -c Release -r win-x64 --self-contained true
```

Собранный автономный исполняемый файл:

```
src\YtDlpGui.App\bin\Release\net8.0-windows\win-x64\publish\Scachalka.exe
```

Запуск тестов:

```powershell
dotnet test
```

## Логотип и иконка

Иконка приложения находится по пути `assets/scachalka.ico` и создаётся из `assets/logo.png` при помощи скрипта [`tools/generate-icon.ps1`](tools/generate-icon.ps1). Чтобы применить собственное изображение, замените `assets/logo.png` квадратным файлом PNG и выполните:

```powershell
pwsh tools/generate-icon.ps1
```

При последующей сборке иконка обновится как для исполняемого файла, так и для окна программы.

## Архитектура проекта

Проект построен на основе чистой многослойной архитектуры со строго однонаправленными зависимостями:

```
YtDlpGui.App            Точка входа: настройка DI-контейнера, жизненный цикл приложения
  ├─ YtDlpGui.UI            WPF-представления, вьюмодели (MVVM), темы, локализация, конвертеры
  │    └─ YtDlpGui.Application   Координатор очереди, исполнитель загрузок, модель задач,
  │         │                    оркестрация импорта медиатеки и массового импорта ссылок
  │         └─ YtDlpGui.Core          Валидация URL, стратегии сборки аргументов,
  │              │                    парсер прогресса, классификатор ошибок, политики повтора,
  │              │                    парсер Apple Music, алгоритм сопоставления треков,
  │              │                    источники ссылок (CSV/JSON/TXT) и анализатор ссылок
  │              └─ YtDlpGui.Abstractions   Интерфейсы, модели данных, контракт локализации
  └─ YtDlpGui.Infrastructure  Запуск процессов (kill-tree), поиск утилит в системе,
                              хранение настроек JSON, логирование, каталоги строк
```

- **Паттерн «Стратегия» для форматов** (`IArgumentBuilder`) — добавление нового формата требует лишь нового класса, без правок существующего кода.
- **Паттерн «Стратегия» для импорта** (`ILinkSource`) — сейчас доступны CSV/JSON/TXT; списки M3U или экспорт из Spotify добавляются без модификации движка импорта.
- **Изолированная логика сопоставления** (`ISongMatchScorer`) — алгоритм подбора треков детерминирован, не зависит от операций ввода-вывода и покрыт модульными тестами.
- **Машиночитаемый разбор прогресса** через `--progress-template` с устойчивым резервным парсером.
- **Защищённый запуск процессов**: передача аргументов через `ArgumentList` с разделителем `--`, исключающим инъекции в командную строку.
- **Надёжная отмена задач**: завершение всего дерева дочерних процессов и очистка временных остатков `*.part`.
- **UI никогда не блокируется**: асинхронный ввод-вывод, сглаженная отправка обновлений прогресса, модификация коллекций строго в UI-потоке.

Подробное руководство по структуре модулей доступно в файле [CONTRIBUTING.md](CONTRIBUTING.md).

## Правовая информация

Scachalka является графической оболочкой общего назначения для yt-dlp. Используйте её только для загрузки материалов, право на сохранение которых у вас имеется. В программе намеренно **отсутствуют** механизмы обхода технических средств защиты авторских прав (DRM) или систем защиты от автоматизированных запросов (anti-bot).
